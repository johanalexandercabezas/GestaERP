GUÍA PRÁCTICA DE CONTINUE + OLLAMA + VS CODE

1.  ¿QUÉ ES CADA HERRAMIENTA?

-   Ollama: Ejecuta modelos de IA localmente.
-   VS Code: Editor donde abres carpetas y archivos.
-   Continue: Extensión que conecta VS Code con Ollama.

Flujo: Tus archivos -> VS Code -> Continue -> Ollama -> Modelo IA

------------------------------------------------------------------------

2.  COMANDOS CON @

Escribe @ en el chat y aparecerán los contextos disponibles.

@Codebase Lee todo el proyecto.

Ejemplos: @Codebase Explícame la arquitectura del proyecto. @Codebase
Busca errores y riesgos.

@CurrentFile Lee el archivo actualmente abierto.

Ejemplos: @CurrentFile Explícame este archivo. @CurrentFile Busca
errores.

@Folder Lee una carpeta.

Ejemplo: @Folder Resume esta carpeta.

@Terminal Lee la salida del terminal.

Ejemplo: @Terminal Explica este error.

@GitDiff Lee los cambios de Git.

Ejemplo: @GitDiff Resume mis cambios.

------------------------------------------------------------------------

3.  COMANDOS ÚTILES PARA UN ERP

Analizar todo el proyecto:

@Codebase Explica toda la arquitectura del ERP.

Buscar errores:

@Codebase Busca errores de seguridad.

Buscar código repetido:

@Codebase Encuentra funciones duplicadas.

Comparar con otros ERP:

@Codebase Compara este ERP con: - Siigo - Alegra - World Office

Indica módulos faltantes y ventajas competitivas.

------------------------------------------------------------------------

4.  ICONOS IMPORTANTES DE CONTINUE

Models: Permite cambiar entre Llama, Qwen, GPT, Claude, etc.

Edit: Modifica archivos con ayuda de IA.

Tools: Activa Terminal, Git, Docs y otras herramientas.

Indexing: Permite indexar todo el proyecto para que @Codebase funcione
correctamente.

------------------------------------------------------------------------

5.  CHAT, PLAN Y AGENT

Chat: Hace preguntas y recibe respuestas.

Plan: Genera planes de trabajo.

Ejemplo: Crea un plan para agregar nómina electrónica al ERP.

Agent: Puede leer, modificar y crear archivos.

Ejemplo: Crea un módulo de inventario para GestaERP con: - categorías -
productos - stock - kardex - alertas - interfaz moderna

------------------------------------------------------------------------

6.  MODELOS RECOMENDADOS

Chat general: llama3.1:8b

Programación: qwen2.5-coder:7b

Español + negocio + ERP: qwen3:8b

Instalar:

ollama pull qwen3:8b

------------------------------------------------------------------------

7.  CONFIGURACIÓN RECOMENDADA

config.yaml

name: Local AI version: 0.0.1 schema: v1

models: - name: Llama provider: ollama model: llama3.1:8b roles: - chat

-   name: QwenCoder provider: ollama model: qwen2.5-coder:7b roles:
    -   chat
    -   edit
    -   apply

------------------------------------------------------------------------

8.  RECOMENDACIÓN FINAL

Para proyectos empresariales y ERP:

-   Ollama -> Ejecuta modelos
-   Continue -> Programa y analiza código
-   Open WebUI -> Analiza Excel, PDF y documentos
-   Qwen3 8B -> Modelo principal
-   Qwen2.5 Coder 7B -> Programación

Con esta combinación puedes trabajar localmente con una IA privada y
potente.
